# OpenYourMouth - TTS

![Slogan do OpenYourMouth](slogan.png)

Um mod para Minecraft que transforma as mensagens que você envia no chat em fala, com vozes e provedores de TTS configuráveis. Personalize a experiência com diferentes opções de voz e áudio. Funciona com **Plasmo Voice** ou **Simple Voice Chat**.

**Recomendamos o uso com Plasmo Voice.**

---

## Instalação

Baixe o JAR correspondente à sua versão do Minecraft na [página de releases](https://github.com/fakemaluco/openyourmouth/releases/latest) e coloque-o na pasta `mods` do cliente. Instale também Fabric API e Plasmo Voice ou Simple Voice Chat para a mesma versão do jogo. Use apenas um JAR do OpenYourMouth por instalação.

## Requisitos

- **Minecraft 1.21.11:** Java 21, Fabric API 0.141.6+1.21.11 e Simple Voice Chat 2.6.22 ou Plasmo Voice 2.1.14.
- **Minecraft 26.2:** Java 25, Fabric API 0.160.0+26.2 e Simple Voice Chat 2.6.23 ou Plasmo Voice 2.1.17.
- **Fabric Loader:** 0.19.3 ou versão posterior compatível.

O servidor e os outros jogadores precisam apenas do mod de voz usado pelo servidor. Eles não precisam instalar o OpenYourMouth.
